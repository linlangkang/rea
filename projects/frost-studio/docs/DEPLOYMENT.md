# 可部署版本

当前只在本机预览，未发布公网。纯静态 Vue + Three.js 应用；方案保存在当前浏览器，不跨设备同步。

## 静态托管

Node.js 24，执行 `npm ci`、`npm run build`，将完整 `dist/` 上传至站点根目录。资源使用根路径，不能直接双击 index.html。支持任意静态 Web 主机，建议启用 HTTPS。域名、证书与平台账号由部署环境配置。

## Docker

在项目目录执行 `docker build -t frost-studio .`，然后 `docker run --rm -p 127.0.0.1:8080:80 frost-studio`。浏览器访问 http://127.0.0.1:8080/ 。`/health` 返回 ok。端口默认仅本机绑定；公网发布时由反向代理提供 HTTPS。

Docker 配置已提供；若本机未安装 Docker，容器运行不能视为已验收。生产构建与本机浏览器交互的结果见当前验收文档。

## 数据与维护

运行 `node scripts/export-catalog.mjs` 生成可导入目录；`public/catalog.json` 是完整目录交换格式。场景引用有严格校验。已有用户保存不会被新版种子覆盖，需导入新版目录或重置工作台。

产品库目前为人工核验种子库，未接入商业平台实时价格、全网爬虫或账户服务。价格空缺不等于免费。所有参数化模型均为结构示意，不代表官方工业模型或实际装机适配认证。

山景和海景是本项目生成资产，位于 public/environment。视觉 V3 新增 public/materials 中的 CC0 贴图和 HDR，必须随构建完整部署。加载失败保留基础天空、材质及配置功能，可点击“重试场景”。资源清单、限制与对照截图见 VISUAL-V3.md。普通运行不需要联网下载材质。2026-10-21 资源优化使用 `npm run assets:pack` 离线处理现有文件；原始下载脚本保留作历史工具，目前受阻来源不得自动重试。

运行资源映射使用内容哈希，需把完整 `dist/` 作为同一版本部署，不能只覆盖 HTML 或部分脚本。`deploy/nginx.conf` 为哈希资源设置一年缓存，为 HTML 设置重新验证，并启用 JS/CSS/JSON/GLTF 文本压缩。WebP 与 HDR 使用各自文件格式；未为了虚构体积下降而删除原始素材。
