# 阮·梅本地接入 V5：实现与验收边界

本次在原霜境项目中实际接入用户提供的三维模型。当前是坐姿和房间融合的可运行调试版，不是照片级成品，也不代表所有穿模问题已解决。

## 资源与授权

- 来源：用户本地 `[本机路径，未公开]` 中名称包含“星穹铁道—阮·梅「雪绽梅笺」”与“盐汽水的猫咪”的目录。
- 原文件：`阮梅_参考图坐姿.blend`，保留不修改。处理副本在项目 `local-assets/ruanmei`。
- 原说明署名：模型编辑“流云景”，版权所属 miHoYo；目录另含“盐汽水的猫咪”，两项保留并列，不擅自合并作者身份。
- 原说明允许改造、优化骨骼和刚体、重制 UV；禁止二次配布及商业用途。因此 GLB 仅通过回环地址的本地专用路由提供，不在 `public`、`dist`、Docker 上下文或 Git 跟踪中分发。
- 部署静态站点时人物文件不会自动附带。缺失时显示错误及重试，配置界面继续可用。

## 真实检查结果

- 原场景 233 个网格对象；主要可见角色网格约 52,863 三角形，其余大量对象是隐藏的 MMD 物理辅助体。
- 384 根骨骼，80 个原始形态键。存在眼球骨骼、`まばたき` 眨眼形态键、独立头发和衣饰骨骼。
- 最终本地 GLB 为 8,753,552 字节、38,628 个三角形、21 个材质分组，保留全部 384 根骨骼及眨眼/微笑形态键。
- 原动作是单帧坐姿，不是现成的持续待机动画。
- 原材质包含复杂 Blender / MMD 节点，不能直接无损导出。引用的 `颜2+1.png` 缺失，处理副本采用目录中已有 `颜3+1.png`；面部效果可能与作者渲染不同。
- 详细原始检查、材质连接、骨骼坐标见 `output/character-v5/inspection.json`、`uv.json`、`export-report.json`。

## 已修改

- `scripts/export-character.py`：在副本中保留身体尺度，通过骨骼调整双臂、披肩与辫子；冻结依赖约束后导出恒定坐姿及蒙皮。只保留网页使用的眨眼、微笑形态键，原资源不删除。
- 清理处理副本中 14,235 个重合面，重新计算面方向；纠正把头发和衣料 Alpha 着色遮罩误当透明度的问题。透明裁切只用于需要的材质。
- `src/scene/character.ts`：独立异步加载及进度、失败重试、骨骼呼吸、非固定间隔眨眼、按真实场景目标求注视方向、头眼不同响应速度、克制的头发跟随、暂停保留姿态、显示隐藏、销毁 GPU 资源。
- 人物固定于同一椅子坐标，统一缩放用于房间匹配，不宣称角色官方身高。相机切换不改变人物坐标。
- `SceneView.vue`：中文人物控制、人物近景与独立加载状态。
- `hardware.ts` / `engine.ts`：风扇叶轮真正旋转，避免每帧遍历整屋查找叶轮；电视画面轻微动态、屏幕时钟、水面顶点运动。
- `panorama.ts`：增加简单的中景山坡和独立水面几何；远景仍使用连续图片，不宣称图片具有真实近景视差或测绘级地形。

## 如何检查

1. 本地预览 `http://127.0.0.1:5179/`，展开左上角“阮·梅 · 人物控制”。
2. 分别选择自然待机、看电脑、看窗外；暂停后姿态应保持，恢复后继续。
3. 人物近景后拖动鼠标环绕，查看真实侧面和背面。人物没有随镜头重新摆放。
4. 原装机配置、选择、拆装及保存恢复沿用原功能。
5. 复现导出：Blender 后台打开 `local-assets/ruanmei/working.blend`，执行 `scripts/export-character.py`；小样地址 `/character-sample.html` 仅用于开发服务器。
6. `node scripts/check-character-room.mjs` 录制实际 Chrome 页面，执行至少 120 秒动画时间，检查根位置不漂移及暂停时间冻结。录屏位于 `output/character-v5/video`，结果在 `room-test.json`。

## 仍存在的限制

现有画质档位保持生效：低档像素比上限 1、关闭阴影、各向异性上限 2；中档为 1.4、1024 阴影、各向异性 4；高档为 2、2048 阴影、各向异性 8。实际像素比和过滤级别同时受设备上限限制。角色目前共用同一网格，没有伪称已经制作三套 LOD。

- 衣饰使用手工骨骼摆放与小幅跟随，没有实时布料、头发碰撞或完整全身 IK。部分视角仍可能出现披肩、裙摆与扶手/坐垫的局部交叠，不能标为“完全无穿模”。任意替换椅子尺寸也没有自动重新求解接触点。
- 眨眼依赖导出的形态键；不是眼睑物理模拟。注视角有舒适范围限制，极端布局下不会无限扭转脖子。
- 原角色保持二次元脸型和贴图；网页 PBR 重建不等于原 Blender Toon 节点逐像素还原。
- 接触阴影包含近似遮蔽贴片，环境照明采用已有 HDRI 与补光，没有完整实时全局光照，也没有接入 DLSS。
- 中景山坡、水面仍是简化示意，房间家具仍有程序化建模痕迹。本轮没有把床品、沙发和窗外全景替换成扫描模型。
- FPS 来自实际渲染帧计数；请同时查看报告中的 GPU、画质、画布尺寸。录屏和并行浏览器会影响帧率，不能把测试数值当作所有机器的保证。

构建与回归验证：`npm run build`、50 项逻辑测试、15 项现有浏览器测试通过。最终人物运行证据以 `output/character-v5/room-test.json` 和对应实际录屏为准。

2026-09-27 最终实测：动画累计 120.669 秒、26 次眨眼、16 次注视状态切换；前后房间布局与人物根坐标一致，暂停计时完全相等，恢复后继续。页面脚本错误记录为空。Chrome ANGLE 使用 Intel UHD / D3D11，画布 860×640、像素比 1，中档录屏采样 23–25 FPS；短时低/中/高档分别为 22/23/23 FPS，不能据此宣称某档更快或已经达到稳定 60 FPS。该视角记录 298 次绘制调用、120,968 个三角形。

实际录屏：`output/character-v5/actual-run.webm` 和转码的 `actual-run.mp4`，包含待机、注视切换、暂停恢复、鼠标环绕与日夜对照，未使用生成视频。
