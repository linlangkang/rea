# 主机几何精修 V10

本轮保留配置、部件 ID、拆装偏移及房间坐标。

- 风扇环由 6×48 段改为 12×96 段；每个环为 2304 个三角形。
- 叶片曲线采样由 5 增至 16，倒角由 1 增至 3 段，九片叶片仍使用实例化。
- 增加固定后支架与电机线，只有叶片转动。
- 主板散热底板厚度从 26 mm 改为 8 mm，避免遮住独立鳍片。
- 补齐机箱后部接口的金属壳、塑料内芯、接点、紧固件和侧板折边。
- 补充电源后部插座、三枚接点、开关及螺钉。

资源为项目原创程序化几何，无新增第三方模型。仍是通用结构示意，不是指定 SKU 的制造 CAD。接口内芯为凹入结构，未对钢板进行真实贯穿布尔开孔。

构建及 54 项单元测试通过。网页八个近景检查无 pageerror；1600×1000 页面中的主机近景记录约 23 FPS，这个短时样本不代表所有硬件或机位性能。曲面精度提高不等于照片级完成，玻璃反射、背板通风结构和品牌级细节仍需继续精修。
