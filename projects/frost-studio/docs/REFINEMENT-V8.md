# 精修 V8：人物手部处理副本与实际场景验证

2026-10-01。本批继续 V7 的场景精修，不代表整个房间达到参考图精度。

## 实际修改

- `scripts/refine-character-v8.py` 从 `local-assets/ruanmei/working.blend` 重新处理原角色。手臂和手腕调整在 MMD 辅助骨骼约束仍有效时执行，随后统一烘焙，避免继续旋转已烘焙骨骼产生的长条拉扯。
- `scripts/export-character.py` 提供姿态、材质处理回调及独立输出路径；原始角色、V5 和 V7 文件保留。V8 文件为 `refined-seated-v8.blend` 与 `ruanmei-refined-v8.glb`。
- 手部权重区域使用独立白色手套材质。保留其他材质的原透明裁切，避免隐藏身体壳显露；这不是新增扫描材质或重新雕刻的手部。
- 网页加载 V8 处理副本；人物资源仍仅由本地开发服务提供，不包含在公开发布包中。
- 网页及 UE 同步缩短脚踏并向前移动，减少与椅轮的重叠；人物根坐标及身材比例不变。
- UE 通过现有编辑器内的文件任务队列导入处理副本、生成独立关卡及实际截图，未关闭或重新启动当前编辑器。

## 明确未完成

- 全身袖摆、饰品与椅背的穿插尚未全面解决。尝试额外旋转左手腕时出现袖口长条拉扯，已撤回这一修改；左手掌朝向及完全自然落手尚未通过验收，不能用自动测试通过替代。
- UE 当前使用导入的固定坐姿，网页的眨眼与注视动画尚未迁移到 UE 动画蓝图。
- 沙发床品仍是精细化参数模型，主机和键盘仍需后续结构与材质精修；没有达到照片级或电影级成品标准。
- UE 与网页脚踏颜色尚未一致。玻璃/Nanite 兼容警告、构建体积警告仍存在。
- 画质采样与 UE 同时运行并录屏，不能视为独占设备下的稳定性能基准。
- 本批未下载新模型或贴图。角色继续遵守原资源仅本地使用限制。

## 工程检查

本轮实际运行 54 项单元测试并全部通过；`vue-tsc --noEmit` 与 Vite 生产构建通过。构建仍报告大于 500 kB 的场景分包提醒。浏览器型号尺寸、颜色、灯光、侧板、十次拆装和保存恢复回归重跑通过（40.1 秒）。首次回归刷新后仍在加载 Three.js，触发原来的 5 秒等待上限；已将刷新等待统一为首次加载使用的 30 秒，全部恢复断言保留。运行录屏和 UE 截图分别验证网页与编辑器，二者不是同一种渲染实现。

降低前臂至更贴近腿面时，原袖口权重也出现拉扯。因此最终处理脚本保留经近景检查的较高姿态，没有将“手自然落在腿上”标记完成。
