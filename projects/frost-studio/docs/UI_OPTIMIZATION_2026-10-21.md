# 霜境：简洁界面与运行效率优化

日期：2026-10-21。项目：`.`。

本轮交付为现有 Vue / Three.js 网页工作台的实际代码修改。设计参考 [Apple 布局指南](https://developer.apple.com/design/human-interface-guidelines/layout) 的信息层级、对齐与内容优先原则。

## 界面

- 浅色中性背景、系统字体、统一间距与圆角。蓝色主要用于保存、选中状态和链接。
- 顶部保留产品库、沉浸预览、保存和更多工具，去掉重复英文副标题与工作台说明。
- 组件列表使用本地 SVG 线性图标，将类别和核验状态合并为一行；长型号保留完整可访问文本及悬停标题。
- 默认显示四个常用视角，窗边、床品、沙发收进更多视角。
- 装配、氛围、设置默认收起，同一时间只打开一个。支持完成按钮、Escape、点击外部关闭及焦点恢复。
- 手机端选中组件直接进入详情；产品库搜索、筛选和卡片适配窄屏。

## 效率与修复

- 产品库先建立产品、来源索引，再筛选；按 24 条分批展示，保留全部记录与加载入口。
- 搜索支持去除首尾空白、大小写无关匹配、一键清空及焦点保留。
- 导入与产品库共用原生模态框，背景不可操作，Tab 循环忽略禁用控件，关闭后恢复焦点。
- 保存时间、预算和来源元数据变化不触发渲染器更新；场景重建键排除报价与来源记录。
- 静态灯光按状态变化更新；去重共享发光材质；缓存冰箱门引用，避免每帧遍历整个冰箱；装配进度稳定时不重复设置零件位置。
- 隐藏标签页和 WebGL 上下文丢失时停止动画循环。重试与卸载加入代次检查，过期异步渲染器释放资源，避免旧回调覆盖新状态。
- 内存容量依据所选套装参数显示；功耗说明不再写死默认 CPU / GPU 数值；清空预算恢复为未填写。
- 使用安装版本提供的 HDRLoader，移除弃用的 RGBELoader 提示；未增加 UI 框架、远程字体或新依赖。
