# 机箱与配件结构升级 · 2026-09-26

本次修改 `src/scene/pc.ts`，新增 `src/scene/hardware.ts`。沿用既有配置、目录、保存及兼容性逻辑，房间布局与界面配色未改。

|对象|原有简化|现在实现|
|---|---|---|
|机箱|盒状板件和少量立柱|喷涂金属框架、独立安装托盘、折边导轨、顶部通风格栅、后部扩展槽、顶置接口、十字螺丝、低不透明度玻璃|
|风扇|矩形直叶片|挤出成型的弯曲叶片、轮毂、环形边框、减振角垫和紧固件；显卡风扇不加 RGB|
|主板|平板加几个方块|薄 PCB、芯片阵列、表面贴装元件、电容、插槽、金属触点、内存卡扣、电源连接器和散热鳍片|
|CPU|单个银色盒|基板、金属顶盖和小型接触结构，组装时位于水冷头下方|
|显卡|整块实心盒|独立 PCB、背板、边框、鳍片阵列、热管、三风扇、供电接口；长度与厚度仍读取当前 SKU|
|内存与 SSD|盒体加发光面|两条独立内存保留选择 ID；补充 PCB、金手指、散热齿、DDR5 标识；SSD 增加芯片、固定螺丝和 NVMe 标识|
|电源与水冷|实心盒与粗管|模块接口、连接触点、水冷排端箱/侧轨/鳍片、实体风扇及胶管|
|线缆|单根粗管|多芯成束线缆、整理扣和弯曲路径，组装状态末端接近对应连接器|

鳍片、叶片、金手指和电子元件采用 InstancedMesh 减少重复绘制。材质区分 PCB、塑料、喷涂金属、拉丝金属和玻璃；小标签为项目原创 Canvas 贴图，本次没有新增第三方模型或纹理授权依赖。原 CC0 室内素材清单见 VISUAL-V3.md。

## 真实度边界

这次增加的是实际网格结构，不是把机箱图片贴到一个盒子上。模型依旧属于参数化结构示意，不是 MSI、联想等厂商提供的原始 CAD，也没有逐型号复刻每个焊点、接口或内部尺寸。不得据此指导真实维修、确认电气针脚或替代安装说明书。

线缆跟随所属部件整体拆出，以保留可读的爆炸图；没有软体动力学、自动拔插动画或全机碰撞求解。风扇叶片为静态模型，不提供风道/温度模拟。玻璃采用透明混合与环境反射近似，没有真实折射或 DLSS 集成。
