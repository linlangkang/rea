# 精修 V7：已实施范围与验收边界

日期：2026-09-29。

本批实际修改了 `models.ts`、`soft.ts`、`room.ts`，不是单纯撰写计划。

- 鼠标：球面变形拱背、较低前端、按键分缝、独立滚轮。
- 耳机：椭圆耳罩、环形软垫和内侧网罩；近景发现网罩被外壳挡住后已调整位置。
- 沙发：靠背和抱枕使用正确的软包厚度方向；降低抱枕使其与坐垫接触，调整扶手搭毯包覆曲线。
- 床品与软包：增加边缘聚拢和非对称填充；减少完全均匀的正弦波纹。这仍是参数化布料，不是布料模拟或扫描资产。
- 茶杯：增加杯口、壁厚、内腔和把手；书本增加封面、书脊和页层。
- 管状轮廓提高径向分段，减轻头梁等位置的多边形轮廓。
- 角色处理副本：抬高两侧前臂、旋转手腕朝向，单独为手部权重区域分配白色手套材质。保留原始 `web-seated.blend` 和 `ruanmei.glb`；新文件为 `refined-seated-v7.blend`、`ruanmei-refined-v7.glb`。原有透明隐藏面仍保留，避免一律改成不透明导致皮肤遮盖层显露。
- UE 补齐此前随人物被排除在房间导出之外的脚踏，网页脚踏同步调整高度。仅表示支撑物已存在，不代表所有腿部和椅轮接触已通过。
- UE 补光显式使用流明并经截图调整；后台截图改为显式触发 SceneCapture，修正多个机位重复同一画面的问题。
- 增加沙发、床品、茶几浏览器检查机位及 UE 耳机、沙发、茶几捕获机位。

UE 更新通过已开启编辑器的本地任务队列执行；新增带时间戳的资产和关卡，不覆盖旧关卡。`cinematic_room.py` 支持请求中的 `refreshGeometry`，顺序导入房间、恢复角色基线、创建精修灯光关卡。`room_sample.py` 在此流程中跳过重复截图任务。家具根位置由原有检查继续验证。
