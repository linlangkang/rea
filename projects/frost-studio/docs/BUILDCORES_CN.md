# 霜境中文装机与空间工作台

用户确认采用独立中文版本，参考 BuildCores 的公开功能与布局，使用霜境自己的品牌、代码与场景。未复制 BuildCores 的商标、模型、商品图片、用户作品或付费资源。

## 页面与流程

- `/#home`：中文首页、原创场景实际截图、三种场景起点。
- `/#build`：独立主机装机页、可编辑名称、费用/兼容性/功耗概览、右侧配件、更换型号、自动旋转/缩放、侧板/拆装、灯效/画质、隐藏渲染、真实 PNG、Markdown 与 JSON 导出、本机归档及独立复制。
- `/#parts`：44 个本地型号、23 类组件，品牌/型号搜索、来源状态筛选、排序、明确目标后替换配件。
- `/#compare`：最多三个型号的规格、来源、采集报价与等比例尺寸比较。尺寸缺失时不绘制该型号；方体不代表实物外形。
- `/#modules`：灯光、夜间环境、侧板、组件目录导入、尺寸比较及 REA 开发工具入口。
- `/#studio`：原有房间、主机拆装、外设、冰箱互动、兼容检查、预算、导入导出与本地保存。

配置、产品目录、兼容性、功耗与预算均读取同一个 Pinia 状态。双显示器必须指定替换位置。首页不创建 WebGL 渲染器；完整房间与尺寸比较按需加载，离开后释放资源。

主机居中展示、方案摘要、分享/导出、配件列表与复制操作参考该页的功能组织。霜境继续使用独立白/蓝品牌；不增加广告、购买、账号或不可用的会员按钮。缺失字段保留“待核验”；实际不兼容结果单独显示。

- 装机渲染只创建主机组件，跳过房间、家具、电视、外景与零食 GLTF；去除主机模式不使用的室内点光源/面光源。几何仍使用现有参数化模型和合批。
- 桌面画布随视口高度调整，1280×720 首屏可操作拆装；手机 390×844 通过标签切换清单。画布离开视口、切到手机清单或页面进入后台会暂停渲染；返回时恢复。隐藏 3D 会释放渲染器。
- 本机方案库最多 8 个，更新按稳定 UUID 进行，复制保留旧归档。旧存档自动补默认名称和空归档 ID；损坏库、容量不足或存储失败保留原数据并提示。
- 分享使用 URL fragment 中的 UTF-8 配置，载荷最大 45KB（编码最大 60KB），超限建议导出 JSON。载入前校验格式、大小和引用，先预览再确认，不自动写入持久存储；分享不携带本机归档 ID。链接包含完整方案及目录，是可读数据，不是加密分享或云端短链接。
- PNG 来自实际 WebGL 画布，不是替代效果图；首次渲染尚未就绪时禁用图片导出/相机操作。Markdown 导出当前主机清单，JSON 备份包含完整工作台配置。

本机原始采集、比较截图、PNG 和诊断数据在 `output/setup-2026-10-22/`。已完成 66 项逻辑测试与生产构建；首次完整浏览器回归 33 项中 32 项通过，持久化测试的相机动画干扰经隔离后，相关 9 项定向复测全部通过。没有将截图时的瞬时 FPS 宣称为通用性能提升倍率。当前精确产品模型、照片级质量和完整空间碰撞仍未完成。
