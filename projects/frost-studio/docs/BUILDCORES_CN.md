# 霜境中文装机与空间工作台

用户确认采用独立中文版本，参考 BuildCores 的公开功能与布局，使用霜境自己的品牌、代码与场景。未复制 BuildCores 的商标、模型、商品图片、用户作品或付费资源。

## 页面与流程

- `/#home`：中文首页、原创场景实际截图、三种场景起点。
- `/#parts`：44 个本地型号、23 类组件，品牌/型号搜索、来源状态筛选、排序、明确目标后替换配件。
- `/#compare`：最多三个型号的规格、来源、采集报价与等比例尺寸比较。尺寸缺失时不绘制该型号；方体不代表实物外形。
- `/#modules`：灯光、夜间环境、侧板、组件目录导入、尺寸比较及 REA 开发工具入口。
- `/#studio`：原有房间、主机拆装、外设、冰箱互动、兼容检查、预算、导入导出与本地保存。

配置、产品目录、兼容性、功耗与预算均读取同一个 Pinia 状态。双显示器必须指定替换位置。首页不创建 WebGL 渲染器；完整房间与尺寸比较按需加载，离开后释放资源。

## 数据边界

没有虚构实时报价、游戏 FPS、社区作品、账户或购买流程。缺失价格显示“暂无报价”，预算是用户估值。演示型号与部分核验型号分别标记，官网来源只支持其列出的字段。默认模型是原创参数化示意，不是产品精确数字孪生。旧方案保存格式保持兼容。
