# 鼠标、键盘及线路精修 V11

实际修改 `src/scene/models.ts`，增加 `engine.ts` 的鼠标与桌下走线检查机位。所有物体布局坐标保持不变。

键盘采用共享的倒角键帽几何与实例化，下凹触面、调整键距、字符层位置和低强度背光。仍是通用紧凑布局，不代表目录中 87 键产品的精确 CAD。

鼠标外壳使用 64×40 分段曲面，底壳改为浅椭圆轮廓，接缝按外壳表面高度生成；增加 32 段滚轮纹、底部脚贴、传感器、充电口。沿用无线鼠标配置。

线路分别使用橡胶护套、塑料接头和金属托槽。双屏线从各自背部引出；键盘加入接头与护线段；主机供电线改为桌下插排至电源附近；补充桌下固定件。现阶段依照默认固定布局生成，尚未建立用户任意移动物体后的动态端点系统，也未模拟线缆重力碰撞。接头及插孔仍为结构示意。

1920×1080 浏览器近景截图位于 `output/refinement-v11/`，由实际网页运行捕获，无生成图替换。截图检查无 pageerror；短时中画质记录键盘 14 FPS、鼠标 17 FPS、桌下线路 26 FPS，同时 UE 打开。不同机位不可直接用于比较单项模型性能。仍需改善字符对比度、物理走线与照明，未达到参考图照片级效果。

新增模型为原创程序化几何，无新增第三方资产。
