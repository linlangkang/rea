# 参考布局升级验收 — 2026-09-23

## 本轮已实现

- 左侧落地窗和桌面、中央沙发、右侧电视柜/冰箱/展示柜、入口床铺。
- 原创山湖/海湾贴图切换、沉浸预览、旧方案应用参考布局（保留已选配件和配色）。
- 产品库搜索、类别/年份筛选、来源链接、换配件、双屏目标选择。
- 33 个产品、44 个配置/颜色记录，其中 23 条有来源；另有 20 条系列资料索引。44 条中含原有演示规格，不是 44 个已完整核验的商业 SKU。
- 联想 2024/2025/2026 系列索引与 2026 冰魄白具体商品记录分开，系列不能冒充确定配置。
- 静态 dist 构建、Dockerfile、Nginx 配置、部署文档与来源刷新脚本。

## 验证

- `npm test`：50/50 逻辑测试通过。
- `npm run test:e2e`：11/11 浏览器测试通过，45.5 秒；Chrome，1600×1000 和 390×844。
- `npm run build`：通过。Three.js 渲染分块约 632 kB 未 gzip，仍有大分块警告。
- IAB 打开生产构建 `http://127.0.0.1:5179/`，实际查看场景并操作沉浸预览与海景切换。
- 性能为当前本机快照，见 `output/playwright/performance.json`；不作为其他设备性能承诺。
- `node scripts/collect-sources.mjs`：13 个明确来源 URL，11 个抓取成功、2 个罗技 URL 返回 HTTP 403。失败保留在 `output/research/source-refresh.json`，不绕过网站限制；罗技条目的内容已通过网页检索工具打开官方发布页核验。
- Docker 客户端存在，但 Linux engine 未运行，未实际构建/运行容器。不等于静态站点无法部署。

## 未完成的范围

没有全网全品牌、全平台、全型号覆盖，也没有实时电商报价。床、沙发、桌椅等仍有演示规格；部分实际产品缺少地区货号、尺寸、BIOS 或端口能力。来源刷新脚本是有限清单的抓取与变更追踪，抓取成功不自动提升核验级别。未发布公网。

视觉实现采用参数化模型，尚未达到参考图写实质量，详见根目录 `design-qa.md`。
