- 工具菜单：目录导入导出、方案备份、UE 配置导出、恢复、重置。支持 Escape 与点击外部关闭。

## 效率

- 产品库、导入弹窗按需加载。主入口构建脚本由之前约 222.5 KB 降至约 214.8 KB，未加载弹窗时无需下载其模块。
- 场景配置更新在同一帧合并，卸载时取消待执行更新；连续调色减少重复重建。
- 画质未变化时不重复设置像素比、阴影选项或调用画布 resize。实际尺寸变化仍由 ResizeObserver 处理。
- 目录使用 SKU / 产品索引，避免每个列表元素重复遍历目录。
- 清除废弃标题、场景提示、固定摘要的 CSS，以及被后续规则覆盖的样式声明。
- 沿用既有 AGENTS.md 与场景规则，不增加重复指令文件。当前 Git 为未产生首个提交的独立仓库，未提交或覆盖其他工作。
